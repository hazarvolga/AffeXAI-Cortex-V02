# Security Policy

AffeXAI Cortex is under active development and has not reached a production release.

Report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository. Do not include credentials, personal data, tenant data, or working exploit details in a public issue.

Security fixes are prioritized by tenant isolation impact, authentication or authorization bypass, remote code execution, secret exposure, and data integrity risk. Supported versions will be listed here when the first production release is published.
